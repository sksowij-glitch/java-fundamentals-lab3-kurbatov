## Пояснення та прев'ю коду

Весь код лабораторної роботи зібрано в єдиному файлі [`Main.java`](Main.java). Усі обчислювальні методи є чистими функціями без прямого виклику `System.out.println` (розділення бізнес-логіки та інтерфейсу користувача).

### Завдання 1: Сума елементів, що кратні 3 (цикл for-each)
* **Пояснення:** Метод перевіряє масив на `null` (кидає `NullPointerException`) та на порожність `length == 0` (кидає `IllegalArgumentException`). Далі за допомогою розширеного циклу `for-each` проходить по всіх елементах. Якщо `element % 3 == 0`, число додається до суми.
* **Прев'ю коду:**
```java
public static int task1(int[] array) {
    if (array == null) {
        throw new NullPointerException("Масив не може бути null!");
    }
    if (array.length == 0) {
        throw new IllegalArgumentException("Масив не може бути порожнім!");
    }

    int sum = 0;
    // Обов'язкове використання циклу for-each
    for (int element : array) {
        if (element % 3 == 0) {
            sum += element;
        }
    }
    return sum;
}
```

### Завдання 2: Сума 3-го та найбільшого додатного елементів (цикл for)
* **Пояснення:** Масив перевіряється на `null` та довжину $\ge 3$. Третій елемент береться за індексом `2` (`array[2]`). У класичному циклі `for` шукається найбільший додатний елемент серед чисел $> 0$. Якщо додатних елементів взагалі немає, викидається `IllegalArgumentException`.
* **Прев'ю коду:**
```java
public static int task2(int[] array) {
    if (array == null) {
        throw new NullPointerException("Масив не може бути null!");
    }
    if (array.length < 3) {
        throw new IllegalArgumentException("Масив повинен містити щонайменше 3 елементи!");
    }

    int thirdElement = array[2]; // індекс 2 відповідає 3-му елементу
    int maxPositive = 0;
    boolean foundPositive = false;

    // Обов'язкове використання класичного циклу for
    for (int i = 0; i < array.length; i++) {
        if (array[i] > 0) {
            if (!foundPositive || array[i] > maxPositive) {
                maxPositive = array[i];
                foundPositive = true;
            }
        }
    }

    if (!foundPositive) {
        throw new IllegalArgumentException("У масиві відсутні додатні елементи!");
    }

    return thirdElement + maxPositive;
}
```

### Завдання 3: Формування масиву C на основі масивів A і B
* **Пояснення:** Метод перевіряє масиви на `null`, на однакову довжину `a.length != b.length` та непорожність. Створюється новий масив $C$ розмірності $n$. У циклі `for` перевіряються умови знаків для кожного індексу $i$: якщо обидва $>0$ — сума, якщо обидва $<0$ — добуток, інакше — $0$.
* **Прев'ю коду:**
```java
public static int[] task3(int[] a, int[] b) {
    if (a == null || b == null) {
        throw new NullPointerException("Масиви не можуть мати значення null!");
    }
    if (a.length != b.length) {
        throw new IllegalArgumentException("Масиви A та B повинні бути однакової довжини!");
    }
    if (a.length == 0) {
        throw new IllegalArgumentException("Масиви не можуть бути порожніми!");
    }

    int[] c = new int[a.length];
    for (int i = 0; i < a.length; i++) {
        if (a[i] > 0 && b[i] > 0) {
            c[i] = a[i] + b[i];
        } else if (a[i] < 0 && b[i] < 0) {
            c[i] = a[i] * b[i];
        } else {
            c[i] = 0;
        }
    }
    return c;
}
```

## Відповіді на контрольні запитання

### 1. Чим змінна відрізняється від масиву?
Звичайна (примітивна) змінна зберігає лише одне окреме значення певного типу.  
Масив — це структура даних (об'єкт у купі), яка містить фіксовану кількість однотипних елементів під одним спільним іменем, доступ до кожного з яких здійснюється за його числовим індексом.

### 2. Що таке стек? Що таке купа? Яка між ними різниця?
- **Стек (Stack):** відносно невелика, швидка область оперативної пам'яті, що працює за принципом LIFO (Last In, First Out). У ньому зберігаються виклики методів, локальні змінні та посилання на об'єкти. Пам'ять виділяється та звільняється автоматично при вході й виході з методу.
- **Купа (Heap):** велика динамічна область пам'яті, де створюються і зберігаються всі об'єкти (включно з масивами).
- **Різниця:** стек значно швидший, але обмежений за розміром; купа призначена для довготривалого зберігання динамічних об'єктів, а непотрібна пам'ять у ній очищується збирачем сміття (Garbage Collector).

### 3. Чи може змінна бути розташована у стеку? Безпосередньо у купі? В об’єкті у купі? Чи може масив бути розташований у стеку? Безпосередньо у купі? В об’єкті у купі?
- **Змінна:**
  - *У стеку:* **Так** (локальні примітивні змінні методів).
  - *Безпосередньо у купі:* **Ні** (окремо самі по собі змінні в купі не існують).
  - *В об'єкті у купі:* **Так** (поля екземпляра класу зберігаються всередині об'єкта в купі).
- **Масив:**
  - *У стеку:* **Ні** (масив у Java є об'єктом, тому завжди розташований у купі; у стеку зберігається лише посилання на нього).
  - *Безпосередньо у купі:* **Так** (при виклику `new int[...]` масив виділяється саме в купі).
  - *В об'єкті у купі:* Сам масив все одно розміщується в купі як окремий об'єкт, а в полі іншого об'єкта зберігається лише посилання на цей масив.

### 4. Чим посилання на масив відрізняється від масиву? Чи може посилання на масив бути розташовано у стеку? Безпосередньо у купі? В об’єкті у купі?
Масив — це безпосередньо сукупність комірок пам'яті з даними в купі. Посилання — це змінна, яка містить адресу ділянки пам'яті в купі, де цей масив розташований.
- Посилання у стеку: **Так** (локальна посилальна змінна, наприклад `int[] arr`).
- Посилання безпосередньо у купі: **Ні** (хіба що як елемент масиву об'єктних посилань).
- Посилання в об'єкті у купі: **Так** (поле класу, що посилається на масив).

### 5. Якщо масив складається з 10 комірок, які індекси мають перша та остання комірки?
- Перша комірка: індекс `0`.
- Остання комірка: індекс `9` (довжина мінус один: $10 - 1 = 9$).

### 6. Що буде, якщо звернутися до неіснуючої комірки у масиві?
Виникне виключення часу виконання (помилка) `ArrayIndexOutOfBoundsException`.

### 7. При створенні нового масиву без явної ініціалізації усі його комірки будуть проініціалізовані:
- **спеціальними значеннями за замовчуванням** (для цілих чисел — `0`, для дійсних — `0.0`, для логічних — `false`, для посилань на об'єкти — `null`).

### 8. Як дізнатися номер першої та останньої комірки масиву, якщо відомо лише посилання на нього?
- Номер першої комірки: завжди `0` (за умови, що масив не порожній, `length > 0`).
- Номер останньої комірки: вираз `arr.length - 1`.

### 9. Як змінити розмір масиву?
Розмір масиву в Java змінити неможливо, оскільки він фіксується під час виділення пам'яті. Щоб «змінити розмір», створюють новий масив необхідної довжини і копіюють у нього елементи старого масиву (вручну або методами `Arrays.copyOf()` / `System.arraycopy()`).

### 10. Що відбувається з масивом при копіюванні посилання на нього?
Новий масив не створюється. Обидва посилання починають вказувати на один і той самий об'єкт масиву в купі. Зміна будь-якого елемента через одне посилання миттєво відображається і через інше.

### 11. Що відбувається з масивом при втрачанні посилання на нього?
Масив стає недосяжним (unreachable). Пам'ять, яку він займав, позначається як вільна та автоматично очищується збирачем сміття (Garbage Collector).

### 12. Чим відрізняються конструкції «for» та «for-each» при роботі з масивами? Які переваги та недоліки кожного з варіантів?
- **`for` (традиційний):**
  - *Переваги:* доступ до індексу `i`; можливість модифікувати значення елементів масиву; можливість обходити масив у зворотному напрямку або з довільним кроком; робота з декількома масивами одночасно.
  - *Недоліки:* більш громіздкий синтаксис; ризик виходу за межі масиву (`ArrayIndexOutOfBoundsException`).
- **`for-each` (розширений):**
  - *Переваги:* простий і компактний синтаксис; виключає помилки виходу за межі масиву.
  - *Недоліки:* відсутній доступ до індексу; елементи доступні лише для читання; обхід можливий лише послідовно від початку до кінця.

### 13. Чи можна у масив «double[]» записати значення «int»? Чи можна у масив «int[]» записати значення «double»?
- У масив `double[]` записати `int` **можна**, оскільки Java автоматично виконує неявне розширювальне перетворення типів (наприклад, число `5` автоматично запишеться як `5.0`).
- У масив `int[]` записати `double` **не можна** без явного приведення типу `(int)`, оскільки це призводить до втрати точності (відкидання дробової частини), і компілятор повідомить про помилку `incompatible types: possible lossy conversion from double to int`.
