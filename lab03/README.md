## Пояснення та прев'ю коду

Весь код лабораторної роботи зібрано в одному файлі [`Main.java`](Main.java). Він написаний просто і зрозуміло, без зайвих ускладнень та без виведення в консоль всередині обчислювальних методів.

### Завдання 1: Сума ряду з коренем та тангенсом
* **Пояснення:** Метод перевіряє, щоб $k$ було від 1 до 14, а $z > 0$. Далі у звичайному циклі `for` від 1 до $k$ обчислюється кожен доданок за формулою та додається до загальної суми. Щоб ділення $k / i$ було дробовим, $k$ приведено до `(double)`.
* **Прев'ю коду:**
```java
public static double task1(int k, double z) {
    if (k < 1 || k >= 15) {
        throw new IllegalArgumentException("k має бути в межах від 1 до 14 включно (отримано " + k + ")");
    }
    if (z <= 0) {
        throw new IllegalArgumentException("z має бути більше нуля (отримано " + z + ")");
    }

    double sum = 0.0;
    for (int i = 1; i <= k; i++) {
        double underRoot = 1.0 / (z * i);
        double term = Math.sqrt(underRoot) + Math.tan((double) k / i);
        sum += term;
    }
    return sum;
}
```

### Завдання 2: Обчислення функції x(t, l)
* **Пояснення:** Метод перевіряє, щоб $t \ge 1$ та $l \ge 1$. За умовою `l % 2 != 0` визначається, чи є $l$ непарним. Якщо непарне — береться $\sqrt{t \cdot l}$, якщо парне — $l / \sqrt{t}$. Оскільки доданок однаковий для всіх кроків суми, у циклі він додається $t$ разів.
* **Прев'ю коду:**
```java
public static double task2(int t, int l) {
    if (t < 1) {
        throw new IllegalArgumentException("t має бути >= 1 (отримано " + t + ")");
    }
    if (l < 1) {
        throw new IllegalArgumentException("l має бути >= 1 (отримано " + l + ")");
    }

    double term;
    if (l % 2 != 0) {
        term = Math.sqrt((double) t * l);
    } else {
        term = (double) l / Math.sqrt(t);
    }

    double sum = 0.0;
    for (int i = 1; i <= t; i++) {
        sum += term;
    }
    return sum;
}
```

### Завдання 3: Нескінченний ряд із заданою точністю
* **Пояснення:** Метод перевіряє точність $\varepsilon > 0$. Знаки чергуються за допомогою простої зміни знака `sign = -sign` на кожному кроці (починаючи з $+1$). Цикл `while` зупиняється через `break`, щойно модуль чергового доданка стає меншим за $\varepsilon$.
* **Прев'ю коду:**
```java
public static double task3(double eps) {
    if (eps <= 0) {
        throw new IllegalArgumentException("eps має бути більше 0 (отримано " + eps + ")");
    }

    double sum = 0.0;
    int i = 1;
    double sign = 1.0;

    while (true) {
        double denominator = (double) i * (i + 1) * (i + 2);
        double term = sign / denominator;

        if (Math.abs(term) < eps) {
            break;
        }

        sum += term;
        sign = -sign;
        i++;
    }
    return sum;
}
```

## Відповіді на контрольні запитання

### 1. Що таке структурне програмування?
Структурне програмування — це підхід до написання програм, за якого код будується з чітких логічних блоків без використання безладних переходів (`goto`). Програма складається лише з трьох базових елементів: послідовності команд, розгалужень та циклів.

### 2. Назвіть основні конструкції структурного програмування.
1. **Послідовність (лінійне виконання):** послідовне виконання команд одна за одною.
2. **Розгалуження (вибір):** вибір гілки коду залежно від умови (`if`, `if-else`, `switch`).
3. **Повторення (цикл):** багаторазове виконання дій за умови (`while`, `do-while`, `for`).

### 3. Назвіть основні принципи структурного програмування.
1. **Єдина точка входу та виходу:** будь-який блок або підпрограма мають лише один вхід і один вихід.
2. **Модульність (декомпозиція):** розбиття складної програми на простіші, незалежні методи.
3. **Низхідне проєктування (зверху-вниз):** рух від загальної мети до деталей реалізації.
4. **Відмова від `goto`:** заборона оператора безумовного переходу.

### 4. Поясніть, чому в більшості мов не радять goto, а в Java його немає?
Оператор `goto` робить код заплутаним і непередбачуваним («спагеті-код»). У Java ключове слово `goto` є зарезервованим, але навмисно не реалізованим; замість нього використовуються цикли, виклики методів і структурована обробка виключень.

### 5. Що таке спагеті-код?
Спагеті-код — це код із заплутаною логікою переходів, у якому складно простежити послідовність дій через надлишок стрибків і переходів.

### 6. Що таке проєктування зверху-вниз? В чому його переваги?
Це підхід, за якого спочатку формулюється головне завдання програми, а потім воно послідовно розбивається на менші підзадачі.  
**Переваги:** спрощує розуміння загальної логіки, полегшує командну розробку та тестування.

### 7. Що таке область видимості ідентифікатора?
Це частина коду, в якій оголошена змінна чи метод доступні для використання. За її межами ідентифікатор недоступний.

### 8. Що таке блок? Як блоки впливають на область видимості?
Блок — це код, обмежений фігурними дужками `{ ... }`. Змінні, оголошені всередині блоку, існують тільки в цьому блоці і видаляються після виходу з нього.

### 9. Коли краще використовувати: `if`, `if-else`, ланцюги `if-else if`?
- **`if`:** коли дію потрібно виконати лише при виконанні умови (наприклад, перевірка аргументу: `if (k < 1) throw ...`).
- **`if-else`:** коли є рівно дві взаємовиключні дії (наприклад, перевірка числа на парність).
- **`if-else if`:** для перевірки кількох послідовних умов або діапазонів значень.

### 10. Переваги та недоліки оператора `switch`:
- **Переваги:** гарна читабельність при виборі з багатьох фіксованих значень одного поля; швидкість роботи.
- **Недоліки:** не вміє перевіряти діапазони значень; обов'язково треба писати `break`, щоб уникнути помилкового провалювання в наступні гілки.

### 11. Чи можна в `switch` використати типи `boolean`, `long`, `double`?
- `boolean` — **ні** (для цього є звичайний `if-else`).
- `long` — **ні** (підтримуються тільки 32-бітні цілі типи: `byte`, `short`, `char`, `int`, а також рядки та `enum`).
- `double` / `float` — **ні** (через похибки представлення дробових чисел у пам'яті точне порівняння неможливе).

### 12. Відмінність `while` та `do-while`:
- `while` — цикл із **передумовою** (перевірка йде перед входом у цикл, тіло може не виконатися жодного разу).
- `do-while` — цикл із **післяумовою** (тіло циклу обов'язково виконається хоча б один раз).

### 13. Що виведе код:
```java
boolean a = false;
boolean b = false;
if (a = false) System.out.println("a is false");
if (b = true)  System.out.println("b is true");
if (a = b)     System.out.println("a = b");
```
**Результат:**
```text
b is true
a = b
```
**Пояснення:** Використано присвоєння `=` замість порівняння `==`. Значення виразу присвоєння дорівнює присвоєному значенню: `b = true` дає `true`, а `a = b` записує `true` в `a` і повертає `true`.

### 14. Що виведе код (switch без break):
```java
int a = 1;
a++;
++a;
switch(a) {
    case 1: System.out.println("1");
    case 2: System.out.println("2");
    case 3: System.out.println("3");
    case 4: System.out.println("4");
}
```
**Результат:**
```text
3
4
```
**Пояснення:** Після двох інкрементів `a = 3`. Програма переходить до `case 3:` і друкує `3`. Оскільки оператор `break` відсутній, виконання продовжується у наступній гілці `case 4:` і друкує `4`.

### 15. До якого результату призведе `sum > 1`?
```java
double sum = 0; 
for (int i = 1; i < 10; i++) {
    sum = sum + 1 / i;
}
System.out.println(sum > 1);
```
**Результат:** `false`.  
**Пояснення:** Вираз `1 / i` є цілочисельним діленням. При $i = 1$ результат $1$, а при всіх $i \ge 2$ результат ділення дорівнює $0$. Тому `sum` залишається $1.0$, а умова `1.0 > 1` є хибною.
