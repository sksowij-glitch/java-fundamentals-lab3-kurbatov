## Пояснення та прев'ю коду

Весь код лабораторної роботи зібрано в одному файлі [`Main.java`](Main.java). Логіка кожного завдання винесена в окремі методи без прямої взаємодії з консоллю, що відповідає вимогам розділення бізнес-логіки та UI.

### Завдання 1: Сума ряду з коренем та тангенсом
* **Пояснення:** Метод перевіряє, щоб $k$ було в межах $[1; 14]$ та $z > 0$ (інакше викидається `IllegalArgumentException`). У циклі додаються значення квадратного кореня та тангенса. При діленні `(double) k / i` виконано явне приведення до `double`, щоб уникнути цілочисельного ділення.
* **Прев'ю коду:**
```java
public static double task1(int k, double z) {
    if (k < 1 || k >= 15) {
        throw new IllegalArgumentException("Параметр k = " + k + " (має бути від 1 до 14 включно)");
    }
    if (z <= 0) {
        throw new IllegalArgumentException("Параметр z = " + z + " (має бути строго більше нуля)");
    }

    double totalSum = 0.0;
    for (int i = 1; i <= k; i++) {
        double underRoot = 1.0 / (z * i);
        double sqrtPart = Math.sqrt(underRoot);
        double tanPart = Math.tan((double) k / i);
        totalSum += (sqrtPart + tanPart);
    }
    return totalSum;
}
```

### Завдання 2: Обчислення функції x(t, l)
* **Пояснення:** Метод перевіряє натуральність параметрів $t \ge 1$ та $l \ge 1$. За допомогою перевірки залишку `l % 2 != 0` визначається парність $l$. Оскільки вираз доданка не залежить від лічильника $i$, він обчислюється один раз і підсумовується $t$ разів.
* **Прев'ю коду:**
```java
public static double task2(int t, int l) {
    if (t < 1) {
        throw new IllegalArgumentException("Параметр t = " + t + " (має бути ціле число t >= 1)");
    }
    if (l < 1) {
        throw new IllegalArgumentException("Параметр l = " + l + " (має бути натуральне число l >= 1)");
    }

    double term;
    if (l % 2 != 0) {
        term = Math.sqrt((double) t * l);
    } else {
        term = (double) l / Math.sqrt(t);
    }

    double totalSum = 0.0;
    for (int i = 1; i <= t; i++) {
        totalSum += term;
    }
    return totalSum;
}
```

### Завдання 3: Нескінченний ряд із заданою точністю
* **Пояснення:** Нескінченний ряд обчислюється за допомогою циклу `while (true)`. На кожній ітерації знак $(-1)^{i+1}$ чергується (+1 для непарних $i$, -1 для парних). Обчислення зупиняється (`break`), як тільки модуль поточного члена стає меншим за точність $\varepsilon$.
* **Прев'ю коду:**
```java
public static double task3(double eps) {
    if (eps <= 0) {
        throw new IllegalArgumentException("Точність eps = " + eps + " (має бути строго більше 0)");
    }

    double totalSum = 0.0;
    int i = 1;
    while (true) {
        double sign = (i % 2 != 0) ? 1.0 : -1.0;
        double denominator = (double) i * (i + 1) * (i + 2);
        double term = sign / denominator;

        if (Math.abs(term) < eps) {
            break;
        }

        totalSum += term;
        i++;
    }
    return totalSum;
}
```

## Відповіді на контрольні запитання

### 1. Що таке структурне програмування?
Структурне програмування — це методологія розробки програмного забезпечення, за якої код будується у вигляді ієрархічної структури логічних блоків без використання безладних переходів (`goto`). Програма складається лише з трьох базових елементів: послідовності команд, розгалужень та циклів.

### 2. Назвіть основні конструкції структурного програмування.
1. **Послідовність (лінійне виконання):** послідовне виконання інструкцій одна за одною.
2. **Розгалуження (вибір):** вибір гілки коду залежно від умови (`if`, `if-else`, `switch`).
3. **Повторення (цикл):** багаторазове виконання дій за умови (`while`, `do-while`, `for`).

### 3. Назвіть основні принципи структурного програмування.
1. **Єдина точка входу та виходу:** будь-який блок, функція або цикл мають рівно один вхід і один вихід.
2. **Модульність (декомпозиція):** складна система розбивається на простіші, незалежні методи й класи.
3. **Низхідне проєктування (зверху-вниз):** рух від загальної архітектури до деталей реалізації.
4. **Відмова від неконтрольованих переходів:** заборона оператора `goto`.

### 4. Поясніть, чому в більшості мов не радять goto, а в Java його немає?
Оператор `goto` створює заплутану логіку («спагеті-код»), яку надзвичайно важко супроводжувати та тестувати. У Java ключове слово `goto` зарезервоване, але не реалізоване навмисно; усі задачі переходів розв'язуються циклами, викликами методів та мітками для `break`/`continue`.

### 5. Що таке спагеті-код?
Спагеті-код — це код із заплутаною, безладною структурою керування потоком виконання, у якому логіка переходів нагадує переплутані макарони.

### 6. Що таке проєктування зверху-вниз? В чому його переваги?
Це підхід, за якого спочатку визначається головне призначення програми, а потім вона розбивається на рівні підзадач.  
**Переваги:** дозволяє зосередитися на бізнес-логіці, спрощує розподіл роботи в команді та тестування через заглушки.

### 7. Що таке область видимості ідентифікатора?
Це частина коду, у межах якої ідентифікатор (ім'я змінної, методу) є доступним для звернення. За межами цієї області змінна не існує.

### 8. Що таке блок? Як блоки впливають на область видимості?
Блок — це сукупність інструкцій між фігурними дужками `{ ... }`. Змінні, оголошені всередині блоку, існують тільки в цьому блоці і знищуються після виходу з нього.

### 9. Коли краще використовувати: `if`, `if-else`, ланцюги `if-else if`?
- **`if`:** коли дію треба виконати лише при виконанні умови (наприклад, перевірка аргументу: `if (k < 1) throw ...`).
- **`if-else`:** коли є рівно два взаємовиключні сценарії (наприклад, парне або непарне число).
- **`if-else if`:** для перевірки діапазонів чи альтернатив із кількох умов.

### 10. Переваги та недоліки оператора `switch`:
- **Переваги:** читабельний і компактний синтаксис при перевірці однієї змінної на багато фіксованих значень; висока швидкість завдяки внутрішній таблиці переходів (jump table).
- **Недоліки:** не підтримує умови діапазонів (наприклад `x > 10`), ризик помилки провалювання (fall-through) при пропуску `break`.

### 11. Чи можна в `switch` використати типи `boolean`, `long`, `double`?
- `boolean` — **ні** (для двох значень призначений `if-else`).
- `long` — **ні** (підтримуються тільки 32-бітні цілі типи: `byte`, `short`, `char`, `int` та їх обгортки, а також `enum` і `String`).
- `double` / `float` — **ні** (через похибки представлення чисел із рухомою комою точне порівняння заборонено).

### 12. Відмінність `while` та `do-while`:
- `while` — цикл із **передумовою** (умова перевіряється до тіла циклу; тіло може не виконатися жодного разу).
- `do-while` — цикл із **післяумовою** (тіло обов'язково виконається щонайменше один раз).

### 13. Що виведе код:
```java
boolean a = false;
boolean b = false;
if (a = false) System.out.println("a is false");
if (b = true)  System.out.println("b is true");
if (a = b)     System.out.println("a = b");
```
**Результат:**
```text
b is true
a = b
```
**Пояснення:** Умовах використано оператор присвоєння `=`, а не порівняння `==`. Значення виразу присвоєння дорівнює присвоєному значенню: `(a = false)` дає `false`, `(b = true)` дає `true`, `(a = b)` копіює `true` в `a` і дає `true`.

### 14. Що виведе код (switch без break):
```java
int a = 1;
a++;
++a;
switch(a) {
    case 1: System.out.println("1");
    case 2: System.out.println("2");
    case 3: System.out.println("3");
    case 4: System.out.println("4");
}
```
**Результат:**
```text
3
4
```
**Пояснення:** Початково `a = 1`, після двох інкрементів `a = 3`. Виконується `case 3:`, і через відсутність оператора `break` керування «провалюється» у наступну гілку `case 4:`.

### 15. До якого результату призведе `sum > 1`?
```java
double sum = 0; 
for (int i = 1; i < 10; i++) {
    sum = sum + 1 / i;
}
System.out.println(sum > 1);
```
**Результат:** `false`.  
**Пояснення:** Операція `1 / i` є цілочисельним діленням: при $i = 1$ результат $1$, а при всіх $i \ge 2$ результат ділення дорівнює $0$. Тому в результаті `sum = 1.0`, а умова `1.0 > 1` є хибною.
